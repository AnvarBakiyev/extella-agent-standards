# Черновики паспортов — не паспорта

Сюда пишет `tools/register_new_agents.py`: он обходит **живых агентов аккаунта** и на
каждого, у кого паспорта нет, заводит черновик из наблюдаемых фактов.

**Машина заполняет только то, что видит:** имя, id, модель, поставщик, права, даты.
Поля «что делает для клиента», «границы», «как откатить» остаются пустыми **сознательно** —
машина их не знает, а правдоподобная выдумка хуже пустоты: на входе у нас стоит гейт
ровно против такой лжи.

**Как довести черновик до паспорта:** заполни пустые поля, убери строку `status: draft`
и перенеси файл в `passports/`. Только там его подхватывают гейт паспортов и ночная
сверка прав — подкаталог `_drafts/` они не читают.

Существующий черновик регистратор не перезаписывает: если ты начал его заполнять,
твоя работа переживёт следующий прогон.
