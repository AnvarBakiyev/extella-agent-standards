# Архитектура названий Extella Evolution

Владелец: Анвар · Дата: 26.07.2026 · Версия: 1.0
Обязательно к использованию во всех продуктах, интерфейсах, документах и коде.

## 1. Продукт и позиционирование

**Extella Evolution** — платформа управления состоянием и развитием ИИ-агентов.
Категория: **Agent Evolution Platform**.

Слоган (RU): «Создайте агента один раз. Развивайте его знания, правила и способности на протяжении
всей жизни.»
Слоган (EN): «The evolution layer for AI agents.»

Отличие от рынка, одной фразой: **Microsoft Agent 365 управляет парком агентов. Extella Evolution
управляет тем, как эти агенты меняются и развиваются.** Мы претендуем не на учёт и наблюдение,
а на управляемое изменение поведения.

Сознательно НЕ используем: «Agent 365» (подражание Microsoft), «AgentOS», «Agent Fabric»,
«Agent Control Plane» — заняты или стали общими рыночными терминами.

## 2. Словарь терминов

| Термин | Что это | Где живёт в коде/продукте |
|---|---|---|
| **Extella Evolution** | весь продукт | верхний уровень |
| **Agent Passport** | **декларация** об агенте: владелец, цель, активная версия, границы, метрика успеха, языки, права | `templates/agent_passport.yaml`, гейт `tools/check_agent_passport.py` |
| **Agent Genome** | **изменяемое содержание** агента: знания, правила, способности, общие обработчики, доступы, интеграции — с происхождением и версиями | вычисляется: `passport.genome` в `tools/build_agent_cabinet.py` |
| **Shared Gene** | общий (наследуемый) элемент генома, который используют несколько агентов | `provenance: global`; основа экрана влияния «используют ещё N агентов» |
| **Agent Cabinet** | взгляд на **одного** агента: паспорт, геном, фактическое поведение, его эволюция | `templates/cabinet_widget.js` |
| **Evolution Console** | взгляд на **весь парк**: агенты, риски, карта общих генов, изменения класса, массовые операции | продукт (бывший «Центр управления агентами») |
| **Evolution Lab** | безопасный полигон: поведение до и после изменения, без вызова живых агентов и без внешних записей | продукт |
| **Evolution Loop** | цикл превращения изменения в рабочее | `AGENT_ARCHITECTURE.md` §5.4 |
| **Evolution Receipt** | квитанция шага цикла: что, кто, когда, с какими версиями и результатом | журнал версий |

```
Extella Evolution
├── Agent Passport   — что заявлено об агенте
├── Agent Genome     — что определяет его поведение (в т.ч. Shared Genes)
├── Agent Cabinet    — где смотрят и меняют ОДНОГО агента
├── Evolution Console — где управляют ПАРКОМ и изменениями класса
├── Evolution Lab    — где проверяют изменение до публикации
└── Evolution Loop   — как изменение становится рабочим (Evolution Receipts)
```

## 3. Два уточнения, без которых термины путаются

### 3.1. Паспорт ≠ Геном (разное назначение)

- **Паспорт заявляет** — это документ-обязательство: кто владелец, зачем агент, какая версия
  активна, чего агент НЕ делает (границы), как понять, что он работает хорошо. Заполняет человек,
  проверяет гейт.
- **Геном определяет** — это фактическое содержание поведения: знания, правила, способности,
  обработчики, доступы. Вычисляется из платформы и журнала, не пишется вручную.
- **Фактическое поведение доказывает** — маршруты реальных запусков и квитанции.

Формула: **паспорт заявляет · геном определяет · фактическое поведение доказывает.**
Расхождение между этими тремя уровнями — не мелочь, а главный предмет контроля (§3.20, §2.2
стандарта кабинета).

### 3.2. Console ≠ Cabinet (разные взгляды, одна механика)

Формулировка «консоль, где управляют отдельным агентом или всей системой» двусмысленна и ведёт к
двум админкам. Разводим согласно решению §2.4 стандарта кабинета:

- **Evolution Console** — парк, риски, карта общих генов, изменения класса, массовые операции;
- **Agent Cabinet** — один агент; изменение общего гена начинается здесь, но завершается в Console.

Данные и журнал версий — **одни**. Cabinet — проекция Console по одному агенту, не второй механизм.

## 4. Правила употребления

1. **Имена продукта не переводим**: Extella Evolution, Agent Genome, Agent Passport, Evolution
   Console / Lab / Loop, Shared Gene, Agent Cabinet — пишутся так на любом языке интерфейса.
2. **Описания и подписи — на двух языках** (§3.26). Русские пояснения к именам:
   Agent Passport — «паспорт агента»; Agent Genome — «геном агента: знания, правила, способности»;
   Evolution Console — «консоль управления парком агентов»; Agent Cabinet — «кабинет агента»;
   Evolution Lab — «полигон проверки изменений»; Evolution Loop — «цикл управляемого изменения»;
   Shared Gene — «общий (наследуемый) элемент генома».
3. **При первом упоминании в клиентском документе** давать расшифровку: «Agent Genome (геном
   агента — его знания, правила и способности)». Слово «геном» без расшифровки в enterprise-разговоре
   вызывает биотех-ассоциации.
4. **Не размножать термины.** Девять — предел. Новый термин вводится только через изменение этого
   файла с утверждением Анвара.
5. Старые рабочие названия считаются устаревшими: «Центр управления агентами» → Evolution Console;
   «Полигон» → Evolution Lab; «Студия способностей» остаётся отдельным демо-каталогом, не частью
   Evolution.

## 5. Что нужно проверить до внешнего использования (не сделано)

- проверка товарных знаков по классам ПО/SaaS в целевых юрисдикциях (RU, KZ, US, EU);
- доступность доменов и социальных имён;
- отдельно проверить «Agent Genome» и «Evolution Console» — как связки они сильнее, чем каждое
  слово по себе; «Evolution» само по себе слишком общее для защиты.

До проверки названия используются как внутренние и продуктовые, но не как зарегистрированная марка.
