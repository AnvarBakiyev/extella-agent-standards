# Приёмка «открывается на чужой машине»

Твоя личная проверка перед выкладкой: открыть приложение на чистом стенде ровно
как покупатель и получить честный светофор. Крутится на **твоём** VPS, под
**твоим** токеном, проверяет **только твой** уходящий продукт. Чужого кода и
чужого доступа тут нет — это не платформенный сервис, а твоя приёмка.

## Как звать (с мака, одной командой)

```
bash ~/priemka.sh <listing_id> [<listing_id> ...]
```

Команда сама сходит на стенд, прогонит проверенный зелёный, скачает скриншот
«глазами покупателя» в `~/Extella-priemka/<id>.png`, откроет его и напечатает
`>> можно выкладывать` или `>> СТОП`. Несколько id за раз — проверит пачкой.
Где взять `listing_id`: из вывода публикации версии в магазин / из ссылки на
листинг. Приложение должно быть выложено в магазин (пусть приватно) — гейт
открывает его страницу, чисто локальную сборку без листинга открыть нечем.

Прямой вызов на стенде (если нужен без обёртки):

```
ssh <стенд> 'cd ~/extella-bench && python3 check_opens_elsewhere.py --домен <listing_id>'
```

Читаешь вердикт:

- **✓ ЗЕЛЁНЫЙ «проверено: открывается»** (код 0) — окно нарисовалось как у
  покупателя. Выкладывай, бейдж зелёный.
- **⚠ ЖЁЛТЫЙ «открывается с оговоркой»** (код 0) — нарисовалось, но в консоли
  есть ошибка рендера. Выкладка разрешена, листинг честно помечен.
- **✕ КРАСНЫЙ «падает у чужого»** (код 1) — пустой экран/спиннер или светящаяся
  подстановка. **Не выкладывай.** Смотри скриншот из строки вердикта.

## Как устроено (чтобы доверять зелёному)

- **Родной origin.** `same_origin_probe.py` сажает браузер на настоящий
  `os.extella.ai` (подмена host-resolver + HTTPS-прокси, добавляющий токен).
  Запросы приложения идут same-origin, как у покупателя; CORS не возникает.
- **Судим по глазу.** Панели ОС рисуют интерфейс в Shadow DOM внутри `#host`,
  которого `--dump-dom` не видит (успех → «ноль текста» в DOM, падение → плашка
  в обычном DOM; текст инвертирован). Поэтому меряем разброс яркости скриншота
  (`convert -format %[fx:standard_deviation]`): пусто/спиннер ≈ 0.010, живая
  панель ≈ 0.136, порог 0.04. Меряем ровно то, что увидит человек.
- **Гибрид.** Блок — только на катастрофе, видимой глазу (пустой экран,
  светящаяся метка). Консольный шум — жёлтое предупреждение, не блок.

Проверено живьём 22.08.2026: настоящий Агент 1С → зелёный; несуществующий
листинг → красный, блок.

## Инструменты рядом

- `probe_window.py` — быстрая проба через прокси (надёжный красный/жёлтый, но
  зелёный неполный из-за CORS с 127.0.0.1). Ей же пользуется ночная канарейка.
- `check_opens_elsewhere.py` — светофор; `--домен` = проверенный зелёный.
- `same_origin_probe.py` — транспорт родного origin.
- `--selftest` есть у гейта: он умеет падать, значит проверяет по-настоящему.

## Чего тут НЕТ (и почему)

**Это не общий сервис.** Никто, кроме тебя, стенд не запускает. Платформенная
авто-проверка всех издателей — отдельная инфра-задача: изолированный раннер на
стороне Extella (контейнер на приложение, одноразовые токены-чужаки, не твой
VPS), и строит её платформенная команда. На личный VPS чужой код не пускаем.

**Бейдж на витрине** считается один раз при выкладке и хранится на листинге —
покупатель читает готовую отметку, стенд в цепочке покупателя не стоит.
Запись бейджа в живой листинг — шаг человека (публикация), не молчаливый.
