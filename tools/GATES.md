# Как запускать гейты — таблица команд

Написано после разбора внешнего чата (стройка Odoo, август 2026): чат читал
исходники гейтов только потому, что не нашёл, как их звать, и несколько раз
передал не тот аргумент. Эта страница закрывает пробел — читать код гейта, чтобы
понять его вызов, больше не нужно.

## Два канонических способа — начинать с них

**Всё разом (то, что видит CI):**

```
bash tools/run_all_gates.sh            # все гейты, режим --selftest
bash tools/run_all_gates.sh --quiet    # только итог и провалы
```

`run_all_gates.sh` гоняет каждый гейт в режиме `--selftest` (гейт проверяет сам
себя на встроенных примерах) и судит по **коду выхода**: `0` — все зелёные, `1` —
есть провал. Это источник истины «57 зелёных».

**По стадии (что обязательно на build / prod):**

```
python3 tools/stage_gates.py --stage build --json     # чату и Console
python3 tools/stage_gates.py --stage prod             # человеку
```

`demo` и `pilot` — синонимы `build`. Список стадий и их состав живут в
`stages.yaml`, не в коде.

## Запуск одного гейта на своём продукте

Часть гейтов умеет проверять конкретный продукт — им передаётся **абсолютный путь
к каталогу продукта**. Три правила, каждое поймано живым чатом:

- **Путь абсолютный, не `.`.** Относительный путь и `.` уводят гейт не туда:
  `check_self_check .` берёт `README.md` корня и падает с посторонней ошибкой.
  Передавать `"$(pwd)/путь/к/продукту"`.
- **Аргумент — каталог продукта, не файл и не корень репозитория стандартов.**
- **Зелёный «проверять нечего» — это не «прошёл».** Гейт, запущенный на продукте
  без поднятого сервера, честно пишет «это НЕ успех: проверять было нечего» и
  отдаёт ненулевой код. Состав ответов сервера так не сверяется — это закрывает
  живая приёмка (H69) и тесты, а не зелёный гейт на статике.

Проверять `--selftest`-ом самого себя умеет каждый гейт (аргумент не нужен):

```
python3 tools/<имя_гейта>.py --selftest
```

## Перед прогоном: та ли редакция стандарта

Чат однажды прогнал гейты из устаревшей копии стандарта, хотя памятка продукта
требовала конкретный коммит. Правило: перед приёмкой сверить, что гейты берутся
из нужной редакции (коммит/версия), а не из случайно оказавшейся рядом копии.
