# История изменений

Правила репозитория: любое изменение документов — только через утверждение Анвара.
У каждой записи: дата, версия, что изменилось, кто утвердил.

## 26.07.2026 — v0.10 — кабинет агента как базовая технология
- `AGENT_CABINET_STANDARD.md`: стандарт кабинета (Паспорт + Эволюция), обязательное разделение
  «как должен работать» / «как работает фактически», защита от массовой поломки при изменении
  общего механизма, честное сравнение с Microsoft Agent 365 (что есть, чего нет и почему).
- `tools/build_agent_cabinet.py`: **генератор кабинета из паспорта** — кабинет не пишется руками
  для каждого агента (самопроверка 16/16; паспорт без границ кабинета не даёт).
- `templates/cabinet_widget.js`: рендер трёх вкладок, двуязычный; защита класса задаёт буквальный
  вопрос «этот механизм используют ещё N агентов…» с выбором «локальная версия / весь класс»
  (рендер-тест 3 вкладки × 2 языка зелёный).
- Живая проверка доступности данных на аккаунте: 15 агентов, 155 знаний, 73 правила, 916 способностей.
Утвердил: Анвар.

## 25.07.2026 — v0.9.2
- Правило §3.26: **русский и английский сразу** — интерфейс, пояснения, ошибки в одном выпуске;
  `agent.languages` обязан содержать `ru` и `en`.
- Правило границ стало проверяемым: у каждой способности обязательны `limits` (чего НЕ делает)
  и `help_surface` (где пояснение на экране). Без них выпуск запрещён.
- Проверялка расширена: правила 11 (границы), 12 (пояснение), 13 (два языка); самопроверка 11/11.
- Добавлены готовые образцы: `templates/help_card.md` (что писать) и `templates/help_widget.js`
  (рабочий код окна из продукта) — новый агент получает пояснение «из коробки».
- `checklists/DoD.md`: пункты про границы и про два языка.
Утвердил: Анвар.

## 25.07.2026 — v0.9.1
