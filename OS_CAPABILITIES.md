Каждое утверждение проверено чтением кода, а не документации. Проверить заново:
`curl https://os.extella.ai/desktop`, взять из ответа имя `desktop.<хэш>.js`, скачать

**Оговорка о полноте.** Панель инструментов в этом замере разобрана частично: перечислен

**Оговорка о безопасности.** Три возможности отсюда выполняют чужой код рядом с токеном
аккаунта: действия правого клика, расширения из магазина и заголовки с подстановкой
`{{token}}`. Разбор — `DEPLOY_REQUIREMENTS.md`, раздел H33. Ниже они описаны со стороны
пользы, и каждая несёт ссылку туда.

## Часть 1. Недооценённое

Четыре возможности, которые есть в оболочке и почти не используются.

### Instruction — библиотека готовых заданий агентам

`+` → `Instruction` создаёт объект-задание: имя и текст. Значение не в хранении, а в
отправке: правый клик по объекту → **`Open with…`** → выбрать агента, и текст уходит
агенту в поле ввода. Сериализуется как `<instruction> имя: текст</instruction>`, агент
получает его через `?prompt=`.

Это готовая библиотека повторяемых заданий: разобранные формулировки лежат объектами на
столе и запускаются по одному агенту нажатием, вместо набора текста заново.

**Ловушка именования.** `Open` и двойной щелчок открывают **редактор** текста — ничего
никуда не уходит. Отправляет только `Open with…`. Название не подсказывает разницу.

### Папка целиком уходит агенту одним нажатием

`Open with…` на папке отправляет её содержимое: файлы, задания, ссылки на веб‑приложения
и агентов — единым сообщением, вложенные папки тоже, до 32 уровней. Собранная папка
работает как готовый комплект материалов к разговору.

Веб‑приложения получают то же сообщение иначе — заголовком `X-Attachment-OS`, то есть
серверная часть приложения может его прочитать.

### Заголовки с подстановкой — вход во внешний сервис под учётной записью Extella

В настройках веб‑приложения задаются заголовки, а прокси ОС подставляет в них значения:
`{{token}}` — токен аккаунта, `{{email}}` — почту, `{{agent_id}}` — идентификатор агента.
Внешнему сайту сырой токен при этом не виден: подстановку делает прокси, страница
загружается без него.

Практический смысл: внешний веб‑сервис узнаёт человека без отдельной регистрации.

**Оговорка.** `{{token}}` — это полный токен аккаунта, а не ограниченный ключ. Диалог
согласия поднимается один раз и запоминается; на `{{agent_id}}` не поднимается вовсе.
Разбор — H33.

### Расширения из магазина — продавец дополняет браузер покупателя

Установка приложения может принести с собой JS продавца, который выполняется на страницах
пользователя. Записи помечены замком и словом Store, правке не подлежат, обновление
подтягивается опросом раз в 12 секунд, пока открыто окно встроенного браузера.

Сильная сторона: продавец доставляет доработку без переустановки продукта. Обратная
сторона — H33.

### Облачный стол — состояние следует за человеком, а не за машиной

Расположение значков, папки, задания и настройки хранятся на сервере: чтение и запись
через `/api/desktop-state`, признак изменений — `/api/desktop-rev`. Это не хранилище
браузера: стол одинаков на любой машине, где выполнен вход.

**Риск, замеренный на практике.** Эндпоинт перезаписывает состояние целиком; удаления
одного значка отдельным вызовом не существует. Однажды пустая запись стёрла стол
с одиннадцатью значками. Сбой записи при этом не показывается: обработка ошибки пустая,
человек узнаёт о потере, только увидев пустой экран.

## Часть 2. Ловушки именования

Три места, где название обещает не то, что делает код.

| Пункт | Что ожидается | Что происходит на самом деле |
|---|---|---|
| `New App` | создать приложение | открывается форма публикации в магазин (`/publish`) |
| `Linked file` / `Linked folder` | привязать файл или папку | заготовка: агенту уходит только **имя**, без содержимого и без пути — путь остаётся пустым, сообщение прямо говорит, что он задаётся позже в приложении |
| `Copy` | скопировать в буфер | дублируется значок на столе; адрес в буфер кладёт **`Copy URL`** |

## Часть 3. Остальной состав

Перечисление с оговорками; поведение проверено выборочно.

**Меню значка приложения.** `Open in browser` — открывает окно ОС, а не системный
браузер. `Rename` — переименование. `Move to Desktop` — работает только для значка
внутри папки. `Hide from All apps` — прячет через `/api/purchase/hide`. `Move to Trash` —
в корзину.

**Панель инструментов** (разобрана частично): магазин, список всех приложений, поиск с
фильтром по типам, тёмное оформление, кнопка возврата на стол, окна встроенного браузера
с вкладками, снимок экрана через `getDisplayMedia`, кнопка `+` для создания объектов.

**Организация стола.** Папки с вложенностью, `Clean up` — раскладка по сетке, выделение
рамкой, перетаскивание с прилипанием к сетке, корзина с удалением, восстановлением
и очисткой.
