# Промпт для чат-агента клиента

Готовый текст, который человек отдаёт своему Claude Code или Codex первым сообщением.
Написан после разбора первых внешних агентов: они не прочитали канон не по лени, а
потому что мы дали то, что нельзя прочитать (свод 369 КБ, ссылка на страницу GitHub
на 497 КБ) и назвали вторым источником публичную справку `api.html`.

**Что изменилось против прежней редакции:**

* ссылки только сырые и только на файлы, которые читаются целиком;
* правила берутся по одному (`rules/H106.md`), а не сводом;
* убрано неверное утверждение «ключ появляется сам при первом запуске приложения» —
  приложение ключ на диск не кладёт (H108);
* добавлено доказательство чтения: назвать номера правил своей задачи;
* сказано прямо, что `api.html` не источник правды;
* сказано, что делать с собственными предохранителями чат-агента.

```
Настройся по стандартам Extella и построй то, что я опишу следующим сообщением.

ИСТОЧНИК ПРАВДЫ — репозиторий extella-agent-standards, и только он. Публичная
справка extella.ai/api.html неполна: рабочих путей в ней нет, и её молчание ничего
не доказывает. Если твой вывод опирается на api.html — он недействителен.

ЧИТАЙ СЫРЫЕ ССЫЛКИ, иначе не прочитаешь ничего: страница GitHub — это 497 КБ
оформления, а свод правил — 369 КБ, веб-чтение его обрезает. Поэтому правила
разложены по одному файлу.

Начни с одной страницы:
https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/AGENT_START.md

Оттуда возьми маршрут под мою задачу. Правило берётся по адресу вида:
https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/H106.md
Оглавление всех правил: .../main/rules/INDEX.md
Когда что-то не работает: .../main/SYMPTOMS.md — вход по симптому.

СРЕДА. Сначала установи, где выполняются твои команды. Подключение делается из
Claude Code или Codex на моём компьютере. Если ты обычный чат или облачная среда
(Claude Code в вебе, Codex в облаке, Cowork), ключ с моего компьютера сюда не попадёт,
а сеть до Extella может быть закрыта: так и скажи, назови шаг для этой среды и не
предлагай выпускать ключ заново.

ПОДКЛЮЧЕНИЕ. Ключ Extella приложение на диск не кладёт — не ищи его и не проси
у меня в чат. Возьми рабочую копию репозитория:
git clone https://github.com/AnvarBakiyev/extella-agent-standards.git
(свою готовую копию не перезаписывай) и из её корня запусти
python3 tools/connect_mcp.py --клиент claude — или --клиент codex, если ты Codex.
Копия нужна для запуска инструментов, правила читай у источника. Нет CLI Claude
Code — скрипт назовёт официальную команду установки; успех другого клиента не
засчитывай. Если ключа нет, скрипт назовёт одно моё действие (кнопка «Подключить
Claude Code и Codex» в приложении Extella Guide; без него — Library → System →
Tokens). В облачной среде кнопка туда не достанет: скрипт назовёт ключ в настройках
окружения. Своих токенов не создавай, ключ нигде не печатай. Различай четыре шага:
ключ готов, клиент настроен, клиент перезапущен, инструмент вызван.

ПРЕЖДЕ ЧЕМ СТРОИТЬ назови номера правил моей задачи и по одной строке на каждое —
так я увижу, что ты их прочитал, а не пересказал общие слова.

ЕСЛИ ДЕЙСТВИЕ ОСТАНОВЛЕНО разрешениями или политикой среды — запиши, КАКОЙ слой
отказал (твой предохранитель, права среды, политика платформы) и дословный текст.
Воспользуйся штатным подтверждением, если оно есть. Не обходи запрет другой
оболочкой, другим экспертом или другим маршрутом и не проси об этом меня. Для
продолжения нужен разрешённый способ или моё действие как владельца.

Отдельно и не про обход: работа НА моём компьютере — это штатная архитектура
Extella, а не лазейка. Эксперт на устройстве выбирается тогда, когда так задумано

Образцы: .../main/experts/dev_connect_assistant.py и
.../main/experts/dev_publish_private.py

НЕ ОБЪЯВЛЯЙ БЛОКЕР БЕЗ ЗАМЕРА. Сначала выполни запрос и покажи код ответа и
дословный текст ошибки. «В документации не описано» — не доказательство.

СТОП-ПРАВИЛА: наружу только черновики; мои данные не покидают мой контур;
разрушающие права не запрашивать; чужое живое не трогать; секреты не едут в архив
и в переписку; отказ объясняется словами и ближайшим действием.

В этом сообщении выполни только подготовку: прочитай вход, подключись, проверь
связь реальным запросом — вызовом list_profiles из этой сессии — и назови правила
моей задачи. Ничего не создавай.
```

## Что отдать человеку вместе с промптом

* приложение **«Разработка на Extella»** в магазине — тот же канон в читаемом виде,
  бесплатно;
* одно предупреждение: **ключ не пересылать** ни в чат, ни документом, ни архивом.
  Если ключ уже куда-то уехал — отозвать его в `Library → System → Tokens` и создать
  новый.
