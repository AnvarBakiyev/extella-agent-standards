# Классы поломок приложений — и чем каждый ловится (предложение стандарта)

**Откуда**: 64 задокументированные находки продукта «Рекрутёр» (Chariot Technologies
Lab) за месяц живой поддержки покупателей. Номера вида №NN — ссылки на журнал находок
продукта; сами классы универсальны для любого приложения магазина.

**Правило стандарта**: чинится не ошибка, а КЛАСС; починка без машинного стража —
это ошибка, которая вернётся. Страж охраняет класс правилом, а не списком имён.

Выжимка из 64 находок журнала Рекрутёра за месяц. Правило чтения: чинится не ошибка,
а КЛАСС; починка без стража = ошибка вернётся. Страж обязан охранять класс, а не
список вчерашних имён (урок №63: жёсткий список «шести функций» пропустил седьмую).

### A. Сборка и доставка
| Класс | Симптом у человека | Страж |
|---|---|---|
| Шов сборки вырезает живой код (№51, №63) | «страница/вакансия не открывается», локально всё работает | универсальная проверка: любая функция исходника, вызываемая сборкой, обязана выжить |
| Правка без пересборки, два источника страницы | «чинили, а ничего не поменялось» | гейт «сборка совпадает с исходником»; панель после подъёма ПЕРЕЧИТЫВАЕТСЯ («это мы?») |
| Архив везёт секреты/ПДн/мусор | утечка, вес | явный список включений + осмотр содержимого ДО упаковки |
| Публикация «прошла», версии нет | тихо потерянный релиз | перечитка листинга после записи — ответ сервера фактом не является |

### B. Страница
| Класс | Симптом | Страж |
|---|---|---|
| Мёртвый обработчик / опечатка в onclick | кнопка «не работает» | гейт проводки: каждый обработчик — на функцию, объявленную в ТОЙ ЖЕ странице |
| Модал-тупик без выхода (№53) | человек заперт в окне | гейт: открылся `add('active')` — обязан где-то закрываться |
| «Успех» на экране без проверки ответа (№49) | «удалено», а оно живо | правило кода + тесты подтверждений |
| Английские заглушки («yrs», «Not provided») | огрызки на русском экране | гейт заглушек; заглушки модели нормализуются в честное «Имя не указано» |
| Экран не перерисовался при смене вида (№47) | «кандидатов нет», а они есть | прокликивание по прогон-листу (машинно не ловится) |

### C. Мост страница↔устройство
| Класс | Симптом | Страж |
|---|---|---|
| Долгий вызов → «deferred, use task_id» (№44) | крутилка и пусто | ТРАНЗИТИВНЫЙ гейт: метод, доходящий до модели по цепочке вызовов, обязан быть в ДОЛГИХ (список руками — забывают) |
| Тело запроса >64 КБ (№50) | «из трёх резюме одно», 400 | передача кусками + тест сборки |
| Родной диалог ОС со страницы магазина (№45) | «кнопка не работает» | правило: страница браузерная — файлы через FileReader |
| Конверт работы разворачивают дальше | вечное ожидание готового | останов разворачивания на объекте со `state` |

### D. Данные
| Класс | Симптом | Страж |
|---|---|---|
| Два писателя затирают друг друга (№48, №33/37) | молчаливая потеря работы | замок + слияние с диском + тест «две программы, обе записи живы» |
| Молчаливое принятие мусора (№39) | кандидат в несуществующей колонке | валидация по словарю + тест отказа |

| Новая версия поверх старых данных | падение/порча после обновления | версия схемы данных + бережное чтение обеих форм (№33) |

### E. Платформа
| Класс | Симптом | Страж |
|---|---|---|
| app_scopes не выданы | страница целая, каждый вызов 403 | просить ОБА права (expert.run + device.run) и перечитывать их после публикации |
| Агент покупки без ключа (№32/38) | «купил — не работает» | платформа (PR #8); обход: экран выбора агента с контрольным запуском |
| Устройство-исполнитель спит (§22) | все вызовы 500 «Target unavailable» | доктор при каждом открытии + кнопка «Проверить и починить» |
| Поле формы игнорируется/становится обязательным; id объектов умирают | публикации ломаются со временем | перечитка после каждой записи; id искать запросом, не хранить вечно |
| Эксперт исполняется чужим питоном (№43) | «No module named …» только у покупателя | sys.path на окружение продукта + перечитка библиотек установщиком |

### F. Среда покупателя
Питон стар / библиотеки не встали / нет места / нет прав / сеть закрыта / часы сбиты /
порт занят / папка в облачной синхронизации — ВСЁ ловится доктором (§ стандарт
«Доктор среды», PR #28): установщик сам чинит что может, продукт проверяет среду при
каждом открытии, отказ несёт кнопку починки и отчёт для поддержки.

### G. Сторожа и процесс (мета-классы — самые дорогие)
1. **Страж охраняет список, а не класс** (№63) — любой жёсткий перечень имён устаревает
   молча. Стражи пишутся правилом («любая функция…», «любой метод, доходящий до модели…»).
2. **Страж сам сломан или врёт** (№34, №35) — новый страж прогоняется на НАРОЧНО
   испорченной копии: не упал на ней — он не страж.
3. **Диагноз без замера** (№46) — «наверное, лимиты» стоило дня; правило: вывод только
   после воспроизведения.
4. **Проверка запрета без проверки остатка** — «эмодзи нет» зелёное на пустых кнопках;
   к каждому запрету — проверка, что на месте запрещённого осталось живое.
5. **Ответ на запись фактом не является** — везде: save_expert, add-version, launchctl,
   pip. Записал — перечитай.
