# How to install the skill

The assistant reads the skill when it builds a screen. Install it once per machine.

```bash
mkdir -p ~/.claude/skills
curl -fsSL https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/en/skills/extella-ui/SKILL.md \
  -o ~/.claude/skills/extella-ui/SKILL.md --create-dirs
```

Check that it's installed:

```bash
head -3 ~/.claude/skills/extella-ui/SKILL.md
```

After that, the assistant will pick it up on its own whenever the interface comes up.
You can also call it explicitly: "load the extella-ui skill and build the screen."

## Update

With the same command. The skill lives in the standards repository, and the
design-code paragraph in it is cross-checked by machine against the guide on every gate
run — they can't drift apart.

## If the design rule changes

It changes in one place — `AGENT_BUILD_GUIDE.md`, section 4.4. The copy in the skill is
then brought in line, otherwise the `check_design_rule` gate turns red and blocks the
merge.
