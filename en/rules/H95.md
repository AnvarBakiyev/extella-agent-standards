# H95. Bilingual RU+EN is mandatory for every app — and checked by machine

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/en/rules/INDEX.md).

### H95. Bilingual RU+EN is mandatory for every app — and checked by machine

Owner's decision, 15 Sep 2026: every app ships in **Russian and English at once**, a later
translation doesn't count. The rule "Russian and English at once" used to live in the guide, but
the gate `check_translation` treated English as optional (stayed silent if there was no
translation at all) — a promise with no enforcement.

**Rule.** The interface, explanations, and error text are bilingual from the start, for every
app. A single-language app does not pass acceptance. The mechanism already exists in the
interface canon: an English original, Russian behind a switch (or the other way around), one
shared OS window language switch.

**How it's checked.** `check_translation` now:
- a section with Russian text and no English → **red** (bilingualism is mandatory);
- a translation that's been started must be **complete** (missing for some sections → red);
- a **fingerprint of the Russian** is stored next to the translation; the Russian changed but
  the fingerprint is old → the translation has fallen behind → red;
- a translation that points to a different file/anchor with a fresh fingerprint is also caught.
Fingerprints are set with `check_translation.py --отпечатки <file>` after translating, not
before — a fingerprint with no translation guards nothing.
