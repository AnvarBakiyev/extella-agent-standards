# H52. A shortcut leads only to the product page's direct address

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/en/rules/INDEX.md).

### H52. A shortcut leads only to the product page's direct address

**Probe from the same chat, 16 Aug 2026.** A page opened through an arbitrary web app or
through a proxy does not get the shell's session: instead of the interface, the person
sees a service response demanding a header.

**Canon for the shortcut.** Only the direct address of the form
`/app-page/{listing id}/`, with a trailing slash. Do not set up a second shortcut by
hand. Do not add a token substitution or your own headers to such a shortcut — those
belong to external web apps and here they produce exactly the refusal they are supposed
to cure (see H33).
