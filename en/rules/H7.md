# H7. Payment for an action — without the user's token

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/INDEX.md).

### H7. Payment for an action — without the user's token

The app creates a request `POST /api/billing/transfer` (no authorization; the gate is
the payer's confirmation), polls `GET /api/billing/transfer/{id}` once every 1–2
seconds, and the OS itself raises a dialog for the payer for **30 seconds**. Confirming
or declining programmatically is **impossible**: the confirmation is protected by a
signed httpOnly desktop cookie and an Origin check — any call from a page, a script, or
curl gets a 403.

Hence: the app **does not need the buyer's token**, `{{email}}` for prefill is enough.
The model "pay per action, not per install" is technically available; the decision to
use it is up to the product owner.
