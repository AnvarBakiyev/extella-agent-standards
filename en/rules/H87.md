# H87. Destructive tests are never run against the owner's production base

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/INDEX.md).

### H87. Destructive tests are never run against the owner's production base

Running destructive settings tests against the production base erased the owner's personal
rule (restored from an earlier snapshot). The owner's data — rules, history, the cabinet — is
their data, not a proving ground.

**Rule.** Destructive tests (creation, overwrite, cleanup) run only on a disposable test base,
never on the owner's or a client's production base. The owner's base is separated from the
tests before they run, not after the loss. Related to H70 (fail-closed before a destructive
operation) and to the boundary "a client's data stays in the client's perimeter."
