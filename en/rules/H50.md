### H50. A REASONING MODEL SILENTLY RETURNS EMPTINESS UNDER A LOW TOKEN CEILING

**Log of the "Building on Extella" chat, 20 Aug 2026.** A reasoning model under a low
token ceiling returns an **empty `content`**, `finish_reason` is filled in, there is no
error code. A silent wrong result: the interface gets emptiness as a valid response.

Fix: for streaming work, take a non-reasoning model, and on refusal name the
`finish_reason` instead of returning emptiness. Probe of the same task: 1.6 s versus
47 s.

This is the same class as "no data is a legitimate answer": an empty answer must be
named, otherwise the product lies with its result. Related to the probe on LLM-judgment
reproducibility.
