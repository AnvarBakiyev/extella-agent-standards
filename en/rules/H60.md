# H60. Editing a page as a new version multiplies versions and agents

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/INDEX.md).

### H60. Editing a page as a new version multiplies versions and agents

**Probe from the console chat, 14 Aug 2026.** Every edit to the page was released as a
new version, and updating the purchase went through in create-new mode. **88 versions**
of one product piled up, along with **26 extra instances** of the agent; the account's
fleet grew to 65 agents with no product-related reason.

**How it looked.** The purchase, the icon, and the open page ended up on different
snapshots. The owner would edit the page and not see the fixes — because he was looking
at the wrong version.

**What to do.** Editing a page is a change to the same version, not a release of a new
one. Updating a purchase only in existing-install mode, with the exact current agent id.
Cross-check the purchase's version, permissions, icon, and version count before and
after. After an authorized cleanup, the fleet shrank from 65 to 39.
