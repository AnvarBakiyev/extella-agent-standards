### H102. ROLLOUT: A FULL RUN, FINGERPRINT CROSS-CHECK, CLEAN STATE

**Source: the 1C Agent chat, an eleven-step release ritual.**

**Measurement and cost.** A full run — **1145 tests**, not just the "affected" ones: half the
defects were caught in unrelated files. Editing the source during the run drifted apart from the
build — the page hash didn't match.

**Rule.** Before rollout three things are mandatory:

* **a full test run**, not a selective one;
* **a storefront cross-check**: print the line "archive and installer carry `<hash>`" — without it
  the store ends up with a version that doesn't match what was built;
* **a clean repository state after the build**: don't touch the sources during the run.

Two recurring platform quirks to build into the rollout script: publishing a version sometimes
times out (retry the step in a loop until confirmed), and deleting the previous version returns
**409** if someone has it installed.
