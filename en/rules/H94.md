# H94. The runtime executes the FIRST top-level function in the file — keep helpers nested

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/INDEX.md).

### H94. The runtime executes the FIRST top-level function in the file — keep helpers nested

A measurement from the Recruiter release (19 Aug 2026, FDE): the helper `def
_archive_from_bundle(...)`, placed before `def rec_install_app(...)`, intercepted the call —
the runtime launched it instead of the function named after the expert, and it crashed with
"got an unexpected keyword argument." That is, the runtime takes the **first top-level function
in the file**, not the one whose name equals the expert's name.

**Rule.** In an expert's file, the main function is the first and only one at the top level; all
helpers are **nested inside it** (the `rec_call`/`mic_record` style). Any top-level `def` before
the main one silently intercepts the call. Related to H68/CSPL (a handler is a single entry
point).
