# H44. An expert's name in an agent's permissions does not make it a model function

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/INDEX.md).

### H44. An expert's name in an agent's permissions does not make it a model function

**Probed by the bridges chat.** The permissions interface saves and returns expert names,
but they are absent from the model's function list: only platform tool names actually
materialize. An install step that checked for the name's presence in the permissions
produced a false green.

**What to do.** Remove the false check, call the expert directly. Bring back granting
access through agent permissions only once an adapter from expert to function exists and
has been measured. This is a neighboring facet of H31: there the platform accepts tool
names that don't exist in the runtime; here it's expert names that never become functions
at all.
