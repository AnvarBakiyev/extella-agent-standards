# H73. The dereference gate must see an id that has traveled into an argument

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/en/rules/INDEX.md).

### H73. The dereference gate must see an id that has traveled into an argument

**The same measurement.** The canon already had a "blind dereference" gate written into it:
it checked literals inside `getElementById(...)` against markup ids, and last time it caught
24 mismatches. This time the id had not traveled into `getElementById`, but into an argument —
`открыть(2,'ш2')` with a button `дп-ш2`. Eight transitions between acts silently drifted out
of the store: the first step worked, the second button stayed forever disabled, the story hit
a dead end, and the gate was green.

**The norm.** The gate checks against markup not only literals inside `getElementById`, but
also strings that travel as an argument to wherever an id gets dereferenced. General rule:
you must check **every place from which an id reaches a dereference**, not one familiar
spelling — otherwise the gate guards against the past mistake, not against the class of
mistake.
