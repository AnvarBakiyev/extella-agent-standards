# H71. Diagnostics print only allow-listed fields — never the raw response or the environment

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/INDEX.md).

### H71. Diagnostics print only allow-listed fields — never the raw response or the environment

An account token ended up in the raw output of a diagnostic command run by an outside
chat, and later a raw HTTP probe printed temporary session and CSRF data. There was a
ban on printing secrets, but it gets bypassed not by malice but by the habit of dumping
"the whole response, just to take a look."

**Rule.** Diagnostic output is assembled from a whitelist of fields: print only the
fields named in advance (the response code, its length, a specific key). Do not print
the raw response in full, the raw environment, or the full headers — not to chat, not
to a log, not to a receipt. What isn't on the whitelist is not printed.
