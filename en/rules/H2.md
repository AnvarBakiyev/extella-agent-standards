# H2. The token arrives as a substitution in `index`, not only as a header

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/INDEX.md).

### H2. The token arrives as a substitution in `index`, not only as a header

The server replaces four placeholders in **index** (and only in index, not in assets):
`{{token}}`, `{{email}}`, `{{agent_id}}`, `{{attachment}}`. The recommended approach is
a single inline script in `<head>` that assembles `window.EXTELLA`.

**A trap that leaks the token.** The substitution is a plain text search over the whole index.
If a placeholder is mentioned in **visible text** (documentation, a hint, a code sample),
the server will write the user's real token right there. Literal mentions must be written
only as HTML mnemonics (`&#123;&#123;token&#125;&#125;`).

And the reverse: if the page was opened **not** through the OS shortcut, the substitution
will not happen and raw `{{…}}` will remain in the lines. The page must recognize this
and say so in words, not fail silently.
