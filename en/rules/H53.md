# H53. Publishing started a second listing instead of a new version

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/INDEX.md).

### H53. Publishing started a second listing instead of a new version

**Probe from the same chat, 14 Aug 2026.** A rollout done through publication created a
NEW listing rather than a version of the existing product. Duplicates appeared on the
desktop and in the store, and it became impossible to say which icon opens which
version.

**What to do.** For a canonical listing, only use adding a version. Cross-check the
exact listing id both before and after the write. Show the version inside the product's
own interface: without it, a person cannot tell a duplicate from a correct install, and
support cannot tell them apart from a screenshot either.
