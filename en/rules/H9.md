# H9. The charge happens after the install

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/INDEX.md).

### H9. The charge happens after the install

Order: balance check → rollout → installer → **the buyer is charged**. Money is not yet
credited to the author automatically: sales are exported and paid out by hand, automatic
crediting is in progress (the owner's word, 27 Sep 2026). A failed install does not leave a
buyer having paid for nothing; reinstalls and free listings are not charged. Hence the earlier
rule about the installer's honest exit code (B3) is about money, not tidiness.
