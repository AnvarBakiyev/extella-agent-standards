### H1. What gets attached

The **`page`** field at publish time, two formats:

| Format | Limits |
|---|---|
| one self-contained `.html` (CSS/JS inline) | **≤ 3 MB** |
| `.zip` bundle with `index.html` at the root | **≤ 20 MB** compressed, ≤ 60 MB unpacked, ≤ 500 files |

A single top-level folder in the zip is collapsed; macOS junk is discarded; `..` in paths is
a 400 refusal. Without `index.html` at the root the bundle is not accepted. Other limits: archive ≤ 100 MB,
extension file ≤ 512 KB, icon ≤ 5 MB, tags ≤ 10.

The platform creates the shortcut to `/app-page/{lid}/` itself and sets it the headers
`X-Extella-Token`, `X-User-Email`, `X-Agent-Id`. **An installer expert is not needed** — it's needed
only to put something onto a device.
