# H39. A thin page in an OS window: its own transport, its own forms, its own windows

Full corpus — `DEPLOY_REQUIREMENTS.md`; rule index — [rules/INDEX.md](https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/rules/INDEX.md).

### H39. A thin page in an OS window: its own transport, its own forms, its own windows

**Findings from the connectors chat, 17–18 Aug 2026.** Three traps with one root: a page
in an OS window lives inside someone else's shell, and habitual web-page techniques break
exactly that shell.

**1. Native form submission replaces the whole window with the service's response.** A
button inside a `form` sends the window off on a navigation, and a browser navigation
carries no access header. The person sees, instead of the interface, the raw response
`X-Extella-Token header required` — the interface is gone, with nowhere to go back to.
The fix is to not use forms at all on such a page: a container instead of `form`, a
button with `type="button"`, and a click handler. The shell additionally intercepts the
submit at the capture stage, before the panel's own handlers.

**2. Overriding `fetch` intercepts the shell's own transport.** The panel installs its own
wrapper around `fetch`, and the shell's very first call to the platform lands in that
wrapper — the result is recursion, the app doesn't open and complains about connectivity.
The fix is to save the real transport BEFORE installing the wrapper (`const osFetch =
window.fetch.bind(window)`), route all calls to the platform only through it, and let the
wrapper serve only the panel's own requests.

**3. The authorization window is created synchronously from the click.** Otherwise the
browser won't open it, and the connection stays stuck waiting forever: the card hangs,
the person doesn't know whether anything is happening, and clicks again. Besides opening
it synchronously, a visible "waiting" note is needed right after the click, the words
"finish signing in," and a separate button to check the status. A hidden endless poll
instead of this is the same silent refusal.
