Подключить мой редактор

Claude Code и Codex работают с Extella по ключу, который лежит на компьютере в файле ~/.extella/api_token.txt. Кнопка сама получает ключ и кладёт его туда, потом проверяет, что он работает. Ключ не показывается ни здесь, ни в чате. В списке токенов он называется «Extella Guide · имя компьютера», там его можно отозвать.

Впиши Device ID и нажми кнопку.

Device ID нужен потому, что окно не знает, на каком компьютере открыто: без адреса ключ лёг бы на компьютер по умолчанию, не обязательно на этот. «Проба без записи» выпускает ключ, проверяет и сразу отзывает, на диск ничего не пишет.
