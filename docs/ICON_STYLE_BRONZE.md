# Bronze Engraved — стиль всех плиток Extella

Спека Анвара, 20.08.2026. Исполняемый источник — `tools/bronze_icon.py`;
при расхождении текста и кода прав код, документ приводится в соответствие.
Старый геометрический генератор (`make_icon.py`) — история, новые иконки им не делать.

## Плитка (метрика 74×74, всё масштабируется линейно; radius = 0.27 × size)

- Фон: `linear-gradient(165deg, #FFFDF9 0%, #F0EBE0 55%, #E4DDD0 100%)`
- Рамка: `1px solid rgba(197,126,51,.35)`
- Тени: `inset 0 1px 1px #fff`, `inset 0 -3px 6px rgba(140,110,60,.14)`,
  внешняя `0 5px 14px rgba(90,70,40,.14)`
  (на тёмном столе внешняя: `0 6px 16px rgba(60,40,20,.28)`)
- Блик: слой поверх, `linear-gradient(180deg, rgba(255,255,255,.6), rgba(255,255,255,0) 45%)`,
  `overflow: hidden` на плитке

## Глиф

- Сетка Lucide 24×24, размер = 0.51 × плитки (38px при 74)
- `fill:none; stroke:#B5722A; stroke-width:1.7; stroke-linecap/join:round`
- Гравировка: `drop-shadow(0 1px 0 rgba(255,255,255,.9))`
  (в генераторе — белым слоем со сдвигом 1px: SVG-фильтр в масштабе сетки глифа
  уезжал, замер 20.08.2026)

## Правила набора — проверяются кодом генератора

- Глифы ТОЛЬКО из Lucide (`templates/lucide/`, вшиты с лицензией ISC);
  руками не рисовать. Один глиф = одна линия, без заливок, текста и логотипов.
- Максимум один золотой акцент — им является сам штрих.
- Сторонние приложения (Astra, Composio, 1C…) оборачиваются в ту же плитку
  монохромным штрихом `#B5722A` — родные PNG не показываем.
- Подпись под плиткой: DM Sans 11px/500, `#8C8C8C`, максимум две строки.
- Экспорт: SVG 1× (генератор кладёт рядом с PNG); растр — для витрины 512
  и macOS .icns при надобности.

## Как сделать иконку

    python3 tools/bronze_icon.py <lucide-глиф> editions/<slug>/icon.png

Установщики (github- и docker-) делают это сами; глиф задаётся `--глиф`,
по умолчанию `app-window`. Новый глиф добавляется в `templates/lucide/`
командой из подсказки генератора.

## Цветные серии (решение Анвара, 21.08.2026)

Стол делится на три серии по цвету штриха; геометрия, крем-фон и гравировка
общие. Исполняемый источник серий — `tools/цветная_плитка.py` (бронзу делает
`bronze_icon.py` как раньше):

| серия | штрих | кому принадлежит |
|---|---|---|
| бронза | `#B5722A` | продукты и агенты |
| петроль-зелёная | `#2F6B66` | офисные инструменты (Документы, Таблица, Заметки, Задачи, Доска, Диаграммы, PDF, Data Privacy) |
| стальная синяя | `#3A6EA5` | управленческие панели (шесть «CEO ·») |

Синий не новый цвет: он уже был акцентом карточек КТ-модулей — серия его
закрепила. Занятые глифы остаются едиными для всех серий; `file-text` перешёл
от Lawyer (плитка в корзине) к «Документам».
