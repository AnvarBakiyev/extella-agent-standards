### H29. FALSY-ПАРАМЕТР НЕ ДОХОДИТ ДО ЭКСПЕРТА. Проверено эхо-экспертом

**Находка команды AGP (первый внешний пользователь), проверена нами 17.08.2026** эхо-экспертом,
который возвращает `repr()` полученного:

| послали | дошло до эксперта |
|---|---|
| `False`, `0`, `""` | **значение по умолчанию** — все три |
| `True`, `7`, `"текст"` | как послали |
| `"False"`, `"0"` строками | как послали |
| `" "` (один пробел) | **значение по умолчанию** |
| ничего не послали | значение по умолчанию |

**1. Ложь и ноль неотличимы от «не передавали».** Эксперт не может узнать, что человек
явно сказал «нет»: он видит свой дефолт. Отсюда правило — **безопасное поведение обязано
быть значением по умолчанию, а включение опасного идти truthy-значением**. Флаг
`подтверждено=False` не защищает; защищает `подтверждено="да"`.

**2. Строка из одних пробелов тоже пропадает** — сверх находки AGP. Пробел как значимый
разделитель параметром не передать.

**Как ловить у себя.** Эхо-эксперт на пять строк, возвращающий `repr()` каждого параметра,
— самая быстрая проверка контракта из существующих.
