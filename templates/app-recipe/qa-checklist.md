# Чек-лист перед выкладкой

## Локально

- [ ] `python3 tools/check.py` зелёный.
- [ ] `python3 tools/build.py` собрал zip; `index.html` в корне zip.
- [ ] Открытие без сети не превращается в пустой экран.
- [ ] Пустой ввод объясняет следующий шаг; не вызывает эксперта.
- [ ] Каждый сценарий меняет и цифру, и таблицу/график.
- [ ] Нельзя ввести отрицательное значение, бесконечность или текст вместо числа.
- [ ] Есть пустое, ожидание, ошибка, готово; у статуса `aria-live`.
- [ ] Нет `prompt`, `alert`, `confirm`, вызовов localhost/internal address.
- [ ] При повторном клике не стартуют два одинаковых запроса.
- [ ] Экспорт, копирование, переход в другое приложение показывают подтверждение только после результата.

## В Extella OS

- [ ] Окно запускается из ярлыка, а не только по прямой ссылке.
- [ ] `etb_init` передаёт тему/устройство, экран остаётся читаемым в обеих темах.
- [ ] Основная кнопка: успех эксперта, ошибка эксперта, тайм-аут.
- [ ] Ответ длиннее обычного не ломает разметку; большой результат не передаётся в UI целиком.
- [ ] Работа в пустом профиле/на втором устройстве не опирается на localStorage первого пользователя.
- [ ] Открыть → выполнить → закрыть → открыть: обещанный результат/файл там, где указан.
- [ ] Проверены все кнопки, вкладки, сценарии, добавление/удаление строк и мобильная ширина.

## Магазин

- [ ] Версия, имя, иконка, описание и скриншоты совпадают с фактическим продуктом.
- [ ] Сначала закрытый листинг и приёмка владельцем.
- [ ] Проверено, что `published` остаётся `false` до отдельного решения о публикации.
- [ ] Нет ключей, токенов, персональных данных и внутренних URL в архиве или логе.
