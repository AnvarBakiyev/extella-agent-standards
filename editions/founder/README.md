# Издание для основателя — состояние

Первое издание, собирается как проверка конвейера. Пользователя мы понимаем лучше всех
остальных: это мы сами. Сегодняшний день — готовое исследование, решения расползались
по чатам, а вчерашние факты врали уже сегодня.

## Состав

| Файл | Что это |
|---|---|
| `edition.yaml` | паспорт, проходит `tools/check_edition.py` |
| `theme.js` | тема: петроль вместо золота, в чужих окнах молчит |
| `expert_fnd_journal.py` | журнал решений **на машине владельца**, `~/.extella/founder/journal.json` |
| `index.html` | страница: один вызов-снимок при открытии, дальше поиск без сети |

## Что уже доказано

* логика журнала прогнана локально: добавление, список, закрытие, отказ на пустом тексте;
* битый файл не затирается молча — ложится рядом копией, а страница говорит об этом;
* запись идёт через временный файл с заменой целиком: половинчатого журнала не бывает;
* страница проходит правило по дизайну: кегли из шкалы, радиусы, ноль теней и градиентов;
* гейт издания зелёный.

## Принято 14.08.2026 живым сценарием

Владелец открыл окно и записал своё решение — журнал показал 4 записи, чтение и запись
пошли на его машину. Это и есть приёмка: не «гейты зелёные», а человек сделал то, ради
чего продукт существует.

По дороге поймали и починили тихий отказ H17 (две обёртки ответа, `repr` вместо JSON) —
исправление уехало **заменой страницы у той же версии**, без новой версии и перепокупки.

тридцать изданий.

## Что осталось (прежний список, для истории)

1. **агент издания** — создаёт человек в интерфейсе Extella (канон A2), нужен `agent_id`;
2. эксперт сохраняется в скоуп этого агента через REST;
3. `УСТРОЙСТВО` в `index.html` — id машины владельца, иначе эксперт уйдёт в облако;
4. публикация предрелизом с правами `expert.run` + `device.run`, покупка себе,
   первый запуск чистым состоянием.

**Гипотеза, которую стоит проверить на этом издании:** канон говорит, что агент, созданный
по API, «не думает» (`pro_key_required`). Но этому продукту модель не нужна — странице нужен
только запуск эксперта. Если API-созданный агент умеет `expert.run`, из сборки издания
исчезает единственный ручной шаг человека, и конвейер становится полностью машинным.
