# Стандарты агентов Extella

Здесь лежит всё, по чему строится агент Extella, и проверялки, которые говорят, готов он
или нет. Два входа — выбери свой.

## Ты строишь агента руками

**[PUBLISH_YOUR_AGENT.md](PUBLISH_YOUR_AGENT.md)** — как оформить репозиторий, чтобы
коллега поставил твоего агента одной ссылкой. Три страницы, без теории.

Живой заполненный пример паспорта:
[extella-1c-agent](https://github.com/AnvarBakiyev/extella-1c-agent).

## Ты Claude, Codex или другое приложение, которое строит агента

**[AGENT_BUILD_GUIDE.md](AGENT_BUILD_GUIDE.md)** — единственный документ, который нужно
прочитать. Он написан для машины: девять решений при стройке, канон платформы, что
выпустить вместе с агентом и цикл «построил → проверил → починил».

Человеку его читать не нужно.

## Проверялки

```bash
bash tools/run_all_gates.sh          # все самопроверки разом
python3 tools/check_agent_repo.py <ссылка на GitHub>   # готов ли чужой репозиторий
python3 tools/check_agent_passport.py passports/<файл>.yaml
```

Проверялка, а не текст, является спецификацией. Если правило нельзя проверить машинно, оно
сформулировано как решение при стройке, а не как требование — и так и помечено.

Гейт, который нельзя пройти честно, сам является дефектом: такие мы чиним, а не обходим.

## Принцип, из которого следует остальное

Ценность агента создаётся не в момент создания, а **на протяжении его жизни**. Собрать
работающую демонстрацию легко; трудно менять поведение живого агента, не ломая его и не
теряя возможность вернуться назад.

Отсюда три следствия, объясняющие почти все правила:

- **заявленное не равно фактическому** — паспорт объявляет, состояние показывает факт, и
  расхождение обязано быть видно, а не сглажено;
- **изменение важнее создания** — у всего есть версия, путь отката и граница
  распространения;
- **молчание дороже ошибки** — операция, ответившая «успех», которого не было, стоит
  недель. Почти каждый дорогой инцидент у нас был именно таким.

Развёрнуто — [EVOLUTION_PHILOSOPHY.md](EVOLUTION_PHILOSOPHY.md).
