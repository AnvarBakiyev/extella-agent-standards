# Модуль «Чтение договоров»

Достаёт из файла договора карточку: стороны, предмет, срок, сумма,
автопродление, срок уведомления о расторжении, подсудность.

## Что делает

Читает договор **на твоём компьютере** локальной моделью и возвращает
заполненную карточку. Незаполненное поле честно помечается «не найдено».

## Чего НЕ делает

| | |
|---|---|
| Не отправляет договор наружу | Текст остаётся на машине. Облако включается только явным разрешением человека — параметр `allow_cloud="да-в-облако"` |
| Не читает PDF | Без сторонней библиотеки текст из PDF достаётся неверно. Модуль отказывается вместо того, чтобы выдумать поля |
| Не читает сканы | Если в файле нет текстового слоя — честный отказ |
| Не даёт юридических выводов | Только выписывает то, что в тексте. Ничего не вычисляет и не советует |

## Что нужно, чтобы он работал

| Нужно | Зачем | Если нет |
|---|---|---|
| Локальная модель на машине (LM Studio на порту 1234) | читать договор, не отправляя его наружу | отказ словами + предложение разрешить облако |
| Файл в формате `.txt`, `.md`, `.rtf`, `.docx` | извлечь текст | отказ с перечислением того, что умеет |
| Extella-кредиты | **не нужны** | — |
| Доступ в интернет | **не нужен** | — |

## Замеры

| Что | Значение | Когда |
|---|---|---|
| Договор на 2,8 КБ, qwen2.5-vl-7b | 29,4 с, 6 полей из 7 | 26.08.2026 |
| Промах | «автопродление» не найдено, хотя пункт есть | 26.08.2026 |

**Про время.** 29 секунд — это близко к пределу в ~51 секунду, после которого
платформа откладывает вызов в фоновую задачу. Для длинных договоров модуль
надо звать с устройства, а не из окна приложения, либо резать текст
параметром `max_chars`.

**Про промах.** Модель находит не всё, и это нормально: она не врёт, а честно
ставит «не найдено». Проверка модуля требует порога, а не идеала — требовать
семь из семи значило бы подгонять тест под удачный прогон.
