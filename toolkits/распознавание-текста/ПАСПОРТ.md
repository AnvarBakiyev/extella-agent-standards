# Модуль «Распознавание текста»

Достаёт текст из картинки или PDF: скан счёта, фотография документа,
PDF без текстового слоя.

## Что делает

Распознаёт **на твоём компьютере** программой tesseract. У PDF сначала берёт
текстовый слой — если он есть, распознавание не нужно и текст получается
точным. Скан раскладывает на страницы и распознаёт.

## Чего НЕ делает

| | |
|---|---|
| Не отправляет картинку наружу | Всё происходит на машине |
| Не ставит программы молча | Установка только по явному `install="да-ставь"`. Без разрешения — отказ с готовой командой |
| Не распознаёт языком, которого нет | Это главное. Tesseract без языкового пакета **не падает** — он выдаёт правдоподобный мусор. Модуль проверяет язык заранее и останавливается |
| Не исправляет и не толкует текст | Отдаёт как распознал |

## Что нужно, чтобы он работал

| Нужно | Зачем | Если нет |
|---|---|---|
| `tesseract` | распознавать | отказ + команда `brew install tesseract` или разрешение поставить |
| Языковой пакет нужного языка | иначе мусор вместо текста | отказ со списком языков, которые есть |
| `poppler` (`pdftotext`, `pdftoppm`) | читать PDF | картинки работают и без него |
| Extella-кредиты, интернет, модель | **не нужны** | — |

## С чем складывается

Модуль [«чтение договоров»](../чтение-договоров/) отказывается от PDF и сканов —
и правильно делает. Этот модуль закрывает ровно ту дыру: сначала распознать,
потом отдать текст на разбор. Так и выглядит сборка способности из модулей.
