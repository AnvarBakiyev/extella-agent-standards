# Как поставить скилл себе

Скилл читает ассистент, когда строит экран. Ставится один раз на машину.

```bash
mkdir -p ~/.claude/skills
curl -fsSL https://raw.githubusercontent.com/AnvarBakiyev/extella-agent-standards/main/skills/extella-ui/SKILL.md \
  -o ~/.claude/skills/extella-ui/SKILL.md --create-dirs
```

Проверить, что встал:

```bash
head -3 ~/.claude/skills/extella-ui/SKILL.md
```

Дальше ассистент подхватит его сам, когда речь зайдёт об интерфейсе. Можно и позвать
явно: «настройся по скиллу extella-ui и сделай экран».

## Обновление

Той же командой. Скилл живёт в репозитории стандартов, и абзац дизайн-кода в нём
сверяется машиной с гидом при каждом прогоне гейтов — разойтись они не могут.

## Если правило по дизайну изменится

Меняется оно в одном месте — `AGENT_BUILD_GUIDE.md`, раздел 4.4. Копия в скилле
приводится следом, иначе гейт `check_design_rule` краснеет и не даёт влить.
